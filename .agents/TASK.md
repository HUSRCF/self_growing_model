# 当前任务定义

更新时间：2026-09-17 UTC

## 已授权的研究扩展

梯度方差后续：比较默认30次单批更新、10次三批平均更新（同30批采样预算）、30次三批平均更新（同更新次数、90批采样）。三组训练种子和有/无评分反馈都保留；每组7个训练留出检查点，开发集不选参数。各批在同一参数状态下反向传播，平均后统一裁剪并更新。

持续优化目标下的下一轮：在隔离脚本中用自由生成轨迹的多步误差训练残差转移适配器（原 GRU/F 冻结），与同容量评分反馈版本对照。只用训练视频前半段；训练视频级留出选择，开发集最终评估。原始模型作为零更新候选，不强制部署新模型。

2026-09-17 新增：用户要求试验将已选事件/q 的评分或置信度反馈进后续模型，以及以现有离散候选点为中心的连续分布。先做独立消融，再考虑组合；训练限训练视频前半段，保留训练视频级验证，开发集评估，冻结包不变。默认先测试 F 输出角度点作为分布中心；q 聚类中心的连续潜变量是另一种接口，已向用户发出可选澄清问题。

用户已授权实现并试验隔离的可变深度搜索原型、优化运行速度，以及修正检查器接口后诊断约束/候选覆盖/价值评分。可训练隔离的价值模型，训练只用训练视频，开发集用于对照；保留原版本包不变。当前运行规模不需要强行使用 120 线程。

## 目标

按 v17 → v18 → v20 的顺序，阅读工作区中的完整版本包，形成可追溯、可持续更新的项目理解，并把关键知识维护在 `.agents/` 中，供后续会话复用。

## 工作范围

- 阅读协议、README、报告、核心运行时代码、训练/评估脚本、冻结记录和关键结果。
- 分清训练、开发选择、冻结测试与事后解释，避免数据泄漏式结论。
- 比较相邻版本的目标、实现、指标、成功项、失败项和遗留问题。
- 校验 ZIP 完整性、文件布局和关键哈希；必要时运行包内自检。
- 每完成一个版本，在 `.agents/versions/` 写详细记录，并同步更新 `.agents/MEMORY.md`。

## 默认不做

- 不重新训练或重新选择模型。
- 不修改版本包中的源码、模型或结果。
- 不把相关窗口当成独立重复实验，不把复用测试集称为全新盲测。
- 不猜测缺失的 v19 ZIP 原因；只有从后续包内证据确认后才记录。

## 交付顺序

1. v17：第一轮阅读已完成，后续版本比较时可补充。
2. v18：下一步阅读与总结。
3. v20：最后阅读；同时识别其内含的 v19 过渡材料。
4. 汇总跨版本演进、当前最佳证据、未解决风险与建议的下一步。
