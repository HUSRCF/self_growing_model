# 事件内小KL评分反馈：减轻损害，没有稳定收益

## 固定实验

保留旧8/32窗口覆盖×上下文/无上下文四种critic和视频leave-one-out，不重选模型或改变目标。

Tnew(r|e) ∝ Told(r|e) exp(−lambda*score(r))。事件概率p(e)不变、原零支持保持，不跨事件直接改根目的分布。每个折仅使用其余9视频的训练状态预测值校准lambda，使mean KL(new joint||old joint)=.01，固定上限1e6。未使用被留出视频标签或评价误差定强度。全部40个折均达到训练平均预算，未触及上限。

每个窗口根目的概率对事件精确求和，后续正常随机续跑。新421017–421020四RNG/P4/300，旧80个观测根窗口；枚举8个根目的、同一组条件续跑标签服务所有策略。目标为单轨迹sincos MSE+2失败，50/100/300平均，**不是U-energy**。这仅验证一次根干预，不代表每步反馈的效果。

零调整概率逐位还原旧prior；四模型的预测分数复现atol1e-12；源报告哈希和F/GRU SHA保持不变。

训练均值校准没有保证留出均值等于.01，更没有约束每个窗口。不能因此声称所有选择都温和、获得安全改进保证。未来若要逐状态约束，应显式实现并验证，而不是事后重新解释当前预算。

## 决策

143项unittest通过；全部32组新候选rollout失败数0；未读hold/DEV/TEST，不推广，不继续对这批数据扫描温度。

当前证据支持“硬替换放大了损害，软反馈可降低干预风险”，但不支持“当前值函数已经能改善预测”。不据此增加搜索深度。

另一个尚未解决的问题是目标匹配：这些critic学的是单轨迹MSE，原主要分布评价含粒子间距离项。下一步可先构造原U-energy下单个粒子动作的边际代价标签（其余粒子按原策略固定生成，枚举该粒子根r），验证与原评分公式和零策略完全一致，再判断这个目标下是否有可重复且可预测的排序信号。不得把现成MSE critic直接称为分布目标值函数；此方案尚未实现。
