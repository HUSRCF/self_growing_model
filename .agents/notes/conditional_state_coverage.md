# 冻结 Q 的中途状态覆盖配对诊断（2026-09-18）

## 问题与控制

上一轮真实25%混合的context策略退步，且实际访问分布上的平均一阶方向已经不利。本轮不改模型、不增加反馈、不调强度，检查原首粒子上的条件价值正面结果能否迁移到其他中途状态。

固定原80TRAIN起始窗口、前缀随机流761017/P8、第51步前真实history/q/hidden。预先指定粒子索引0/1/2/3（人类计数第1/2/3/4个），所有状态的模型选择在生成新标签前确定，不按未来误差挑状态。

参考库固定811000/P16原完整预测，后续随机流固定811017–811020、每个八动作4分支、续跑250步；各状态组使用相同批大小与随机数布局。只有实际中途状态变化，Q模型、参考与后续随机流不变。首组811017全部标签/失败逐位重算，首组其余三个旧流复用；不是宣称四旧流全部重新采样。

指标仍为1秒/3秒能量一阶影响差，相对于每个实际状态自己的prior，不是有限混合真实评分，也不是MSE。报告预测差与实测差，但预测差因选择argmin天然非正，不能仅凭其负号认为策略有效。

## 限制与复现
