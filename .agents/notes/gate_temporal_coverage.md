# 拟合侧时间覆盖：不是简单的远离训练样本

2026-09-18；实现 `audit_gate_temporal_coverage.py`，结果 `adaptive_search_results/gate_temporal_coverage.json`。

仅10个拟合TRAIN视频，每视频前/后段各64个均匀唯一历史起点，共1280窗。排除原80拟合起点；后段历史完全位于视频中点之后，比旧尾段评价首历史可跨中点的定义更严格，因此不是原留出窗口的直接复现。加载视频用于历史提取，没有提取未来目标、生成轨迹、计算损失或拟合参数，没有读取另外3个TRAINhold/DEV/TEST视频。视频内窗口有重叠。

冻结全量门控模型，原80历史特征的均值/标准差逐位复现；来源hash不变。最近邻参照固定为原80历史，排除同视频参照，距离分别在标准化并clip±3的61维空间及固定8维tanh投影空间计算。这些距离是描述量，没有训练异常阈值，也不保证反映真实分布支持。

| 描述量 | 前段640窗 | 后段640窗 |
|---|---:|---:|
| 角增量RMS中位数（rad/步） | .172828 | .093380 |
| 原两档核低运动档占比 | 50.78% | 96.09% |
| 任一坐标触发裁剪的窗口占比 | 22.97% | 5.16% |
| 被裁剪坐标占比 | .4764% | .0897% |
| 61维裁剪空间跨视频最近邻距离中位数 | .596105 | .582382 |
| 8维投影空间跨视频最近邻距离中位数 | .307064 | .300484 |
| 3秒alpha均值 | .808977 | .868473 |

后段q=0/4/6合计578/640（90.31%），前段296/640（46.25%）。所有10视频的后段运动中位数都下降，但9/10视频后段3秒alpha均值增加（19例外）。其他时距alpha总体下降：0.5秒 .863446→.825085，1秒 .804763→.760848。

结论：拟合侧本身存在明显时间状态比例变化，不能把历史hold后段问题全部归于新视频。按当前两种有限特征距离，后段没有更远，简单“距离远就回退”缺乏支持；并不能由此证明不存在其他意义的分布偏移。原低运动档混合了较宽状态范围，单一阈值不能保证门控知道何时收缩。没有未来误差标签，因此本审计不能证明alpha应当降低多少，也不能证明上述变化导致了性能退化。

下一步建议：先固定10拟合视频的时间分块协议，在不更新模型的条件下生成前/后段的新轨迹和精确点L/Q标签，验证该侧是否也存在“扩散收益反转”；然后才比较前段重加权与加入时间覆盖训练、或联合alpha/核宽。新训练协议必须保留未用于拟合的时间块及原点/标量对照，不能直接使用过去hold负结果设置阈值。本步尚未执行。

验证：新增区域隔离、去重排除、跨视频近邻、短视频/非法区域测试，共176项测试通过；无模型变更或推广。
