# 延后干预实际状态诊断（2026-09-18）

用户方向：将被选 event/q 的评分反馈给模型，或将离散候选点变为以这些点为中心的连续分布。已有闭环反馈、连续过程扰动和输出周期核实验，不能将其当作尚未尝试的新方案；目前均无稳定通用收益，详见 closed_loop_policy.md、first_point_distribution.md 和 energy_kernel_temporal_shift.md。

## 本次新增实验

只使用原 80 TRAIN 窗口、761017–761020 四条随机流、每窗口 8 粒子。为 continuation 增加可选只读快照，记录读入第 1/51 步之前的真实 history/q/GRU hidden/failed/RNG 状态，不重新初始化记忆。

有/无记录的完整轨迹及失败标记逐位相同；第 51 步前历史与生成点 19–50 逐位相同；machine.read 不修改快照。用旧 mixture_terms 的独立索引求和顺序回放旧 baseline，逐位相同。首次直接 energy_costs 回放出现最大 4.44e-16 差异，源于全矩阵求和与排除对角索引求和的次序不同；保留轨迹精确断言，改用同一归约实现，未放宽门槛。mixture_terms 仍独立核对两种等价评分误差 <=1e-14。

标签固定为 r6/.25 延后干预相对原模型的 1 秒和 3 秒平均 full-mixture U-score 变化，越负越好。特征为窗口内 8 粒子均值；不是单粒子 advantage。

## 结果

起点 q6 占比为 104/640=16.25%；实际第 51 步前为 64–74/640=10.0%–11.56%。不能把预测起点 q 当作干预时 q。

同一窗口用另外三条随机流平均收益作标签，描述性 Pearson 相关：

| 特征 | 起点 | 第 51 步前 |
|---|---|---|
| p(r6) | -0.291 至 -0.195 | +0.051 至 +0.121 |
| q6 粒子占比 | -0.287 至 -0.190 | +0.060 至 +0.127 |
| 路由熵 | +0.085 至 +0.128 | -0.174 至 +0.022 |
| hidden RMS | -0.143 至 +0.024 | -0.109 至 +0.076 |

干预时 p6 视频内去均值相关仅 -0.003 至 +0.088；hidden RMS 和熵没有跨流一致关系。此证据不支持直接用“概率高就更值得强制选择”作为 gate。

另三流共享初始窗口与真实未来，但递归产生的第 51 步状态不同；这些不是同一个干预状态的四次独立收益测量，也不是四个独立数据集。相关不能证明因果、预测能力或无信息；hidden RMS 只是粗摘要，不能据此否定完整 hidden 的作用。当前 r6 标签还是集合级干预，不能直接监督逐粒子的反馈网络。

## 后续边界

优先明确反馈目标：模型选择概率 p(e)/p(r) 表示偏好，不等于未来质量 Q。若增加 learned-Q feedback，应以实际访问状态为输入，因果在线计算分数，按视频交叉拟合，以同容量零反馈为对照；不能给推理输入真实未来误差。

连续分布仍需区分输出密度校准（不回灌）与过程分布（采样点递归进入模型）。保留零方差/原模型对照，宽度只在训练侧学习，分别检查短/长时距、视频和时间迁移。已有固定中心宽度的失败不等于所有联合学习中心/协方差方法不可能，但不宜重跑同一宽度扫描。

本轮没有训练新 gate、选择阈值、增加状态容量、访问晚段/hold/DEV/TEST 或修改默认模型。4 CPU 进程，每进程 BLAS/OMP 1 线程。223 项测试通过；原 F/GRU 与源报告 hash 不变，数值失败 0。

复现：`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python audit_delayed_state.py`。输出：`adaptive_search_results/delayed_state_audit.json`。
