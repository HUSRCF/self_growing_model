# 历史运动条件偏移：排除视频评价失败

2026-09-18；实现 `conditional_output_shift.py`、`crossfit_conditional_output_shift.py`；产物 `adaptive_search_results/conditional_output_shift_{models,evaluation}.json`。

## 协议

120个拟合侧状态（80前段+40较早后段），逐视频留一，每折108窗。训练轨迹固定原482017/621017/P32；折内log历史RMS标准化、clip±3。每时距2角各一个截距和斜率，共4参数，输出及系数均限±.25rad，.001全部系数L2、单零初值、L-BFGS200。失败或训练正则损失不优回退零。

与原共同偏移（2参数/时距）及零偏移比较；原共同偏移折参数逐位回放。全部模型冻结后才生成新681017/681018/P32评价轨迹，仍在同120状态上按排除视频模型评分。没有晚段评价/hold/DEV/TEST、没有超参数扫描。仅校准器排除视频，骨干仍见过TRAIN，不是全系统盲测。

## 结果

原点平均U=.415190527；共同偏移delta+.000062907（两seed+.000486932/-.000361118）；条件偏移delta+.001301513（两seed+.001553539/+.001049486），两次均退化。

条件偏移0.5/1/3秒delta+.001571106/+.000612802/+.001720629，全部退化。前段delta-.000086594，较早后段+.004077726；仅4/10视频改善。不能只报告微弱前段收益或条件模型训练收益。

29/30拟合收敛且选择非零校正。排除视频19的3秒拟合`ABNORMAL`，按既定规则回退零、保留该折，没有重试、删样本或放宽边界。没有系数触边。训练和评价保护失败0，来源hash不变。

195项测试通过，包括条件偏移解析梯度、每窗共同平移的粒子对距离不变、幅度和零回退；模型序列化预测逐位回放。

## 决策

不采用运动条件输出偏移，不进一步在hold上检查已失败候选。共同偏移与简单运动条件偏移均没有可靠迁移收益；降低继续扩展输出平移模型容量的优先级。这不证明所有条件校准都不可能有效。

下一步回到事件/q选择链路：先检查仓库中既有策略/价值/路由诊断及负结果，再确定尚未覆盖的行为差异，避免重做已有root critic或搜索试验。此轮没有修改事件、q或主动力学。
