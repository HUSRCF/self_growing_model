# event 解析边际化评分梯度

2026-09-17。`audit_marginal_event_gradient.py`、`test_marginal_event_gradient.py`、结果 `adaptive_search_results/marginal_event_gradient_audit.json`。

## 方法与边界

保持原event→r抽样及两组uniform不变，完全共享生成轨迹。额外累计 `marginal_logp = sum_t log(sum_e pe[e]*T[e,r_t])`，替代评分项中的联合event/r logprob；路径导数、留一粒子优势和全部300步目标不变。旧logp接口和默认训练策略保留。

该操作依赖当前模型结构：数值F只用q/r，readhidden在采样前已算好，不直接依赖抽中的e。若未来event有专属提交记忆，该边际化不能直接沿用。

在原2步toy三个theta，逐一枚举4种r路径及对应event路径，联合logprob导数的后验加权平均等于边际logprob导数；路径概率加总也一致。P3的4096联合组合U-energy期望中，联合/边际混合梯度均与精确求导一致（rtol1e-11、atol1e-12）。这不解决真实硬守卫边界求导问题。

## 真实配对结果

复用上轮固定theta0、10个TRAIN拟合前半段窗口(seed190101)、P4、300步和8动作seed321017–321024（窗口j加j*100000）。旧完整联合梯度逐项精确复现，轨迹为两个估计器共享；没有重训、裁剪、调参、留出选择或DEV/TEST。

| 估计器 | 原始梯度样本协方差迹 |
|---|---:|
|联合event/r|8.466712e7|
|边际r|1.933403e8|

比值2.28354；8种删一seed的比例1.329–3.669。不能据此宣称总体边际化增加方差：条件平均在适用条件下的总体性质，不保证每个小样本经验方差排序。也不能用理论性质将本次实测较大波动描述成成功降噪。

全部梯度有限，无失败守卫触发；119项回归测试通过，原F/GRU SHA不变。

## 逐窗口定位

- seed321020、video15/start121，边际梯度norm约307715。
