# 软混合门控LOVO：固定权重优于仅运动特征的门控

2026-09-18。`soft_kernel_gate.py`、`crossfit_soft_kernel_gate.py`、`test_soft_kernel_gate.py`；报告 `soft_kernel_gate_models.json`、`soft_kernel_gate_evaluation.json`。附 `audit_soft_gate_oracle.py` / `soft_gate_oracle_diagnostic.json` 只读事后诊断。

## 协议与正确性

沿用原10折各自9视频拟合的两档条件核，源模型/主模型hash不变。每折仅9视频72窗口、旧482017/P32计算精确点L/Q，2049/4097全alpha∈[0,1]网格差验收后拟合门控。训练系数已保存，可供后续固定协议实验复用，避免重复昂贵积分。

每时距对照：alpha0原点、alpha1完整条件核、训练均值二次目标在[0,1]的精确标量最优、状态门控。标量解比较端点与合法驻点，不假定有限P的Q非负。

状态门控alpha=clip(b0+b1*z,0,1)，z是仅9视频拟合的log(历史RMS+1e-12)标准化并clip±3。固定b0[-2,3]/b1[-2,2]、单起点[.5,0]、惩罚.001*b1²、L-BFGS200。若不收敛或正则训练目标不优于标量，则预定回退标量。30次拟合均收敛，全部选择状态候选；标量alpha范围 .811624–.990457。

全部门控冻结后才生成571017/571018两个新动作流/P32，评价排除视频同80状态。门控拟合轨迹与核拟合轨迹相同，不是独立校准数据。主模型原TRAIN训练，因此只是适配器/门控层CV，非全系统盲测。没有hold/DEV/TEST或推广。

## 事后未来真值oracle（不可部署）

仅用已保存评价系数，逐窗口/时距选择未来真值最优alpha。第一RNG选择、第二评价：Δ−.01319287；反向−.01329702。它们仍使用同一窗口未来真值，不能当泛化证据或可学习收益保证，也不是严格误差上界。同seed选择评价更乐观：−.01581480/−.01662776。

两组oracle在240个窗口-时距中分别选alpha0共93/86个、alpha1各110个，权重跨RNG相关.70978。相比状态门控零选择0个，表明“是否平滑”的离线选择仍有空间；不能推断仅凭当前历史一定能预测它。

## 决策与下一步

不把仅历史运动的门控带到留出调参，也不重复扩大其MC作为主要下一步。优先验证更丰富但因果的状态表征是否能预测上述收益差异：保持折内核和已有训练L/Q，特征归一化仅用9视频，预先固定小容量/正则及标量对照，新门控冻结后用新RNG评价排除视频。不能用oracle选择更新评价状态的门控，不能将这两次已看过的RNG再冒充独立确认。尚未实施。
