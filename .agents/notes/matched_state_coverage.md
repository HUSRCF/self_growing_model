# 等标签采样预算：单状态重复与多状态覆盖（2026-09-18）

## 预先固定的对照

前轮冻结Q对新中途状态的收益减弱，但不足以解释全部有限干预失败。本轮真正重新训练，比较采样预算分配，不只继续做相关诊断。

- single：80原TRAIN窗口的首粒子状态，每状态使用811017–811020四流×4分支的标签均值。
- multi：同80窗口的四个预先指定实际状态，分别使用自然对角流：粒子索引0/1/2/3对应811017/18/19/20，每状态4分支，共320行。
- 两者每窗口/每动作都使用16后续分支，同811000/P16参考分布、1秒/3秒平均影响标签；多状态不额外增加4倍标签轨迹预算。
- 各自保留action-only与context模型，形成2×2对照。既有128随机投影seed1901/ridge .01N/clip±8规格不变；十折按视频排除，标准化也仅使用拟合视频。

对角分配已在上一轮记录中预先固定，不按标签优劣选组合。等的是标签轨迹预算，不是拟合CPU或整个研究历史的总消耗；multi有4倍训练行、更多不同状态、每状态标签更嘈杂。此比较仍只有一次固定分配，不能排除分配噪声。

## 验证和评价

四种模型全部JSON冻结，训练侧预测序列化逐位相同。所有实际状态hash、prior与原覆盖报告逐位核验。旧821017/P16冻结策略原baseline、全部混合评分以及L/Q逐位回放。

冻结后新831017–831020四流/P16，从原80初始窗口生成全部粒子的真实中途状态；第51步按各粒子的Q选择一次目的，之后保持原递归。比较完整.75原分布+.25干预分布的U-score（包括跨分量独立索引的粒子距离），并保存L/Q；不能用训练影响标签替代该评分。固定r6对照也运行并保留在原始报告中。

前50步逐位相同，0.5秒评分差结构为零。无晚段/hold/DEV/TEST、无每步反馈/比例搜索或默认模型变更。骨干见过TRAIN，仅新critic拟合按视频隔离；新随机流不是新视频泛化。
