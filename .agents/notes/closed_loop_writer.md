# 直接闭环优化两参数连续writer：选择收益未通过新RNG

2026-09-17。`train_closed_loop_writer.py`，`validate_closed_loop_writer.py`；结果 `closed_loop_writer_seed{1901,2718,3141}.json` 与 `closed_loop_writer_validation.json`。

## 预定方法

原GRU、事件→q抽样和F不变，F后加两个常数角校正参数。参数从0开始，归一化box[-1,1]；实际bound=[4.420470599130084e-5,7.863518817316617e-5]rad，固定为既有10TRAIN拟合真实历史99%残差cap的1%。不使用DEV定界。

每个优化种子1901/2718/3141训练12轮；每轮从10拟合视频前半段各刷新2窗口、P4、300步，完整评估当前/正方向/负方向3候选，同窗口同动作RNG，选该批评分最低者。方向随机单位向量，步长.5/sqrt(iteration)，box投影。优化实际50/100/300步U-energy+失败代价均值，不对离散采样求导，也不声称这是无偏梯度法。

每种子36次训练rollout、864000粒子步、240窗口抽样（实际不同窗口239/237/239）。每0/4/8/12轮，在TRAIN3复用留出视频24窗口P8、seed62017/62019检查，保留epoch0。三个优化种子全部保留，不挑最好seed。三者epoch0目标逐项相同。
