# 连续writer的路径导数+离散路由score梯度验证

2026-09-17。实现`hybrid_writer_gradient.py`，报告`adaptive_search_results/hybrid_writer_gradient.json`。仅可穷举玩具验证，不读取真实数据、不训练真实模型、不新增DEV/TEST。

## 模型及穷举

2步、2事件、2q，冻结状态/hidden条件路由，连续writer有2参数。事件影响r，数值规则只由连续状态/q/r/参数决定；读后hidden递归进入下一步路由。共16完整动作路径，P3独立粒子共4096联合路径组合，终点sin/cos嵌入的U-energy作为目标。

对3预定参数点[-.15,.07]、[0,0]、[.2,-.1]比较：直接对全部路径概率×损失之和求导；概率detach后的路径损失导数；detach损失×路径logprob的score项；两项相加；score项使用留一粒子基线的版本；中央差分epsilon1e-5。

完整估计器=可微集合损失 + sum_i stopgrad(损失−留一粒子基线_i)*logprob_i。只在score项detach优势，不截断生成状态到后续路由概率的导数；基线不参与路径项。该表达式用于一阶梯度，不能把surrogate数值当实际损失或直接声明高阶导数正确。

## 结果

三点完整梯度与精确梯度在rtol1e-11/atol1e-12内相等，使用/不用基线都成立；中央差分rtol1e-6/atol1e-8内相等。路径和联合概率总和为1，其梯度为0。完整梯度分别：

```
[-1.8135038152603342, -0.12877541010289253]
[-1.8217982888646438, -0.25397748257219044]
[-0.4335246243755447, -0.11751732544905650]
```

仅路径导数的遗漏范数为.0006268/.00004786/.0007541；非零但本例很小，不证明真实任务score项很大。仅score项也漏掉主要连续路径导数。将路由输入state/hidden detach时，前向值完全不变，却失去本例的参数→路由概率梯度，说明仅做前向一致性不够。

初版测试错误地要求所有点的遗漏>1e-4，其中零参数点真实遗漏4.79e-5；保留模型/数据/结果不变，修正测试为>1e-8以检查非零且超过数值误差，而不是假设实用效应大小。111项回归测试最终通过。

## 限制及下一步

没有证明有限采样方差比黑盒搜索更低，没有真实任务收益，也没有解决失败守卫、ReLU/clip边界、历史特征标准化等实现问题。

下一步：对真实冻结F及GRU写可微CPU float64桥接，先验证真实历史特征、所有(q,r)候选、事件概率/转移概率/hidden与现有NumPy实现一致；再验证固定动作短轨迹与参数导数的有限差分。初始q来自与参数无关的历史可固定，但后续读取的连续历史/hidden不能无意detach。真正训练前需明确非光滑守卫的处理与有效范围；不得仅凭本玩具无偏性就给真实守卫系统同样保证。该桥接尚未实现。
