# 随机续跑候选值函数：存在标签信号，跨视频预测尚未获益

2026-09-17。`audit_crossfit_value.py` 与 `adaptive_search_results/crossfit_value_audit.json`。

## 与旧排序器的区别

旧 `train_search_ranker.py` 用top2事件×top2目的、贪心续跑10/25/50步标签，历史DEV候选评分.004593差于prior .004451。没有重复其短贪心方案。

新方案仅10个TRAIN拟合视频前缀，每视频随机8窗口(seed401017)。枚举全部8个根目的r，之后恢复原双uniform事件优先随机采样，P4/300步。冻结实现里给定r后e无额外作用，不重复64个等价根分支。根干预不是部署时绕过事件的授权。

402017/402018各生成一批标签用于训练，403017/403018独立生成评价标签；各候选共用随机数降低配对噪声。每批每候选的标签是粒子平均单轨迹sincos4维MSE+2失败，再平均50/100/300步。**不是U-energy**，不同目标的数字不能横比。

按视频leave-one-out训练，以候选子历史/目的q/读后hidden及源q作因果特征，不输入未来。每折归一化排除被留出视频；固定128个随机tanh特征、正则.01*N、候选内特征和标签均中心化。没有调参或检查点选择。冻结主干本身见过这些TRAIN视频，因此只称新critic的视频隔离，不称全模型盲测。

正常无干预轨迹与原NumPy unchecked实现300步逐位相同。32组候选rollout全部无失败。

## 独立标签评价

|根选择|综合代价|相对原概率加权|
|---|---:|---:|
|原概率加权|.334224|0|
|原概率众数|.332624|−.001600|
|跨视频值函数最小值|.339646|+.005421|
|拟合标签最小值（不可部署）|.321526|−.012698|
|评价标签最小值（乐观oracle）|.255006|−.079218|

原概率加权是sum_r prior(r)*条件续跑均值，为原根采样策略期望代价的估计，不是额外跑的一条抽样轨迹。

值函数两评价seed分别恶化+.005160/+.005682；10视频5改善5恶化，整体约+1.62%。两批标签候选内中心化后的相关性.47204；值函数预测与独立标签优势相关性.11706。选择次数8个r均非零，不是全局单一r崩塌。

拟合标签oracle使用同窗口未来真值，不能部署，但在另一批RNG上仍平均改善，提示标签并非纯噪声。评价oracle直接使用被评价的标签挑最小值，收益高度乐观，不能当可实现上限。仅两个评价seed、80个相关窗口，以上不是总体显著性证明。

## 决策与局限

不接管事件、不反馈部署、不推广默认。139项unittest通过，F/GRU SHA不变，未读hold/DEV/TEST。本轮只测观测历史根的一次干预，不证明生成状态上逐步策略的效果。

下一步优先隔离“预测器学到上下文了吗”：加入按视频交叉拟合的无上下文目的偏好基线，并用固定更密TRAIN窗口覆盖检查值函数学习曲线；保留相同独立评价窗口/标签，不根据其结果扫描容量或正则。若依旧不能胜过prior，则先停止价值驱动深搜。未来要接入分布目标，还需设计与粒子U-energy匹配的边际行动价值，不能把此单轨迹MSE critic直接称为分布最优值函数。
