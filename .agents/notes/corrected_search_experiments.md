# 修正后的搜索实验（2026-09-17）

## 实现与验证

原型 scalar `_child` 和 batch `_expand` 的 left_history 均改为 `history[:, :-1]`，使检查器取到中点左邻居。新增 `test_adaptive_search.py`：恒速输入验证 checker 实际收到的左邻居及中心速度；四个开发视频状态验证 scalar/batch 候选、拒绝行为和分数一致。两项测试通过。

新增 `--widen-on-empty`：当前节点 top-2 event × top-2 q′ 全部无效时，扩展全部 event/q′；仍保留 event→q′→F 的顺序。新增 `--soft-check`：有限但超过统计阈值的分支保留，使用原分数惩罚；非有限候选仍拒绝。两者是隔离消融，默认关闭。

## 开发集结果

同一 32 窗口、50 步、温度 0、2 个重复粒子；每个配置只计算一次确定性路径。误差是 embedding RMSE。

| 配置 | 0.1秒 | 0.25秒 | 0.5秒 | 0.5秒失败率 |
|---|---:|---:|---:|---:|
| 固定深度2 | .005636 | .016964 | .035752 | 0 |
| 可变深度2–3 | .005636 | .016963 | .035754 | 0 |
| 可变深度+空节点加宽 | .005636 | .016963 | .035754 | 0 |
| 可变深度+软检查 | .005801 | .019595 | .039288 | 0 |

加宽运行中 4,875 个窄搜索空节点，仅 4 个可被完整扩展救回，4,871 个仍无有效候选。这是树内节点计数，不是独立窗口失败。加宽未改变最终误差。软检查在此次开发对照中更差；不能推广为所有软似然策略无效。

## 复用测试集验证

预定固定2与可变2–3两组，无测试调参；64 窗口、50 步。固定2 RMSE .092618、耗时26.5秒；可变2–3 RMSE .092649、耗时34.5秒，平均深度2.487。两者0.5秒失败率均为0，全部64窗口有效。此前错误接口版本2/64失败已消失。确定性重复粒子覆盖率仍为0，不应当作校准分布，也不能与官方8随机粒子/300步窗口表直接比较（tail_windows随horizon改变起点）。

## 小型价值模型负结果

`train_search_value.py` 生成13个训练视频前半段的832个候选状态，10个训练视频拟合、3个完整训练视频留出；标签是相同贪心无检查续推策略在1/10/25/50步的平均embedding MSE。输入为因果连续特征、q one-hot、GRU hidden。采用固定随机tanh特征+ridge，未使用开发/测试标签拟合。

留出MSE .001422，常数基线 .001318，相关系数 .0888。每组四候选的预测最优选择真实代价 .009666，所有候选均值 .011263，知道未来的oracle .002831；说明可能存在微弱排序信息，但泛化及候选识别仍不足。该模型未启用到正式搜索；`--value-model`/`--value-weight` 仅提供后续研究接入。它估计固定续推策略的代价，并非最优价值；训练只有首个生成分支状态，缺少更深自由rollout状态，接入深节点存在分布偏移。

后续优先：扩大训练状态覆盖；用同前缀候选的成对排序目标；按整视频验证候选选择regret；验证通过后再比较价值引导搜索。单纯增大深度或直接放松阈值尚无支持证据。
