# 根概率调整空间：跨随机流 oracle 诊断

2026-09-18。`audit_root_selection_space.py`、`test_root_selection_space.py`、报告 `adaptive_search_results/root_selection_space.json`。

只复用 `full_root_distribution.json` 的80个TRAIN拟合根状态、451017–451020四流、每根分量P4的A/B缓存，原prior评分逐位回放。固定九候选：原prior，以及各根r对应的 .75prior+.25onehot(r)。每次用另外三流平均评分逐窗选候选，在排除流评分；另保留同流选择的乐观结果。无新轨迹、模型拟合、hold、DEV、TEST或默认更改。

平均跨流Δ = −.019533399691671994，相对原prior .460460737约改善4.24%。四折Δ为 −.018913108/−.021137930/−.018537679/−.019544882；十个视频的平均Δ均负。原prior被选比例 .003125。同流oracle Δ = −.05375825641915723，约11.68%，明显更乐观；三流选择与排除流选择一致率20.625%。

这是使用同窗口未来真值的不可部署诊断。跨RNG不消除未来标签泄漏，不是新视频泛化或严格可实现上界；四折训练流重叠，不能当四个独立估计计算显著性。P4有限标签噪声大，一致率低也可能包含近似并列候选，不能单独视为无信号。

197项测试通过，缓存SHA未变。该结果表明完整分布下的有限根概率调整仍存在跨流重复的选择空间，但并未证明历史特征可预测它。
