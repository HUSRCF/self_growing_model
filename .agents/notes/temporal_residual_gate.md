# 时间隔离训练：覆盖扩展有缓解，残差门控无增益

## 协议变更与边界

门控训练首次加入10拟合视频的部分后段标签。原80前缀精确L/Q复用，再加每视频4窗、共40窗，历史起点>=中点、目标结束<3/4边界，动作seed621017/P32。120窗等权，故前/后权重80:40，不是时间区域等权。旧条件核、F、GRU保持不变，核仍只由原80前段拟合。

新标量、运动、丰富门控沿用既定训练算法；丰富特征归一化只在120窗拟合、随机投影仍固定seed1901。新增 `alpha=clip(motion_alpha+.25*tanh(x@beta),0,1)`，9参数包括截距，全部系数.001L2、盒±2、单零初值、L-BFGS200，训练正则损失不优或失败则回退运动。9次拟合全部收敛、全部选择非回退模型；模型序列化同批预测逐位复现。

冻结写盘后才加载末1/4评价块：每视频4窗共40，最早评价历史>=3/4边界，逐视频断言训练最后目标<评价最早历史。新622017/622018 P32，全9策略共享轨迹。区内窗口可重叠；历史视频/相邻区间以前被看过，不能称项目盲测。无hold/DEV/TEST、无据结果调参或推广。
