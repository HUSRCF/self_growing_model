# 固定增量校正方向的正常状态保护缩放

2026-09-17。`protected_residual_pilot.py` 和 `validate_protected_residual.py`。

## 协议

固定已拟合的增量校正器。对10个TRAIN拟合视频的真实历史，取原限幅校正d、wrapped真值残差r和冻结候选概率p，解析求解 a=clip(E[p*r*d]/E[p*d*d],0,1)。均值含两个角维度。这只最小化平均局部拟合角残差二次误差；不保证每状态/每视频、留出或闭环不恶化。没有用留出挑幅度。

系数与cap同时乘a，实现a*clip(raw,cap)，不是仅把原系数乘a而保留原cap。原模型文件不变。实际所有采集状态上验证缩放输出等价；零校正保留。TRAIN留出3个复用视频、24窗口、8粒子、300步，首组新动作seed42017–42020；后续固定模型追加52017–52024，不做DEV/TEST。
